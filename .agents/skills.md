# Repository skills

Skills are reusable instructions for work that needs extra, focused guidance. Each skill lives in its own directory and is activated when the task matches its description.

## Available skills

- `.agents/skills/flutter-ui/SKILL.md`: use for Flutter screens, widgets, navigation, responsive layouts, Material 3 styling, and user interactions.

Add a new skill only when a recurring task has clear conventions that do not belong in the general project rules. Keep each `SKILL.md` focused and include when to use it, conventions, verification, and common pitfalls.
